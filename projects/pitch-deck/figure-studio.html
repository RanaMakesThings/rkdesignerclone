Why This Works

It avoids asking a model to invent both the argument and the layout at the same time.
It forces every figure into an archetype with a clear focal point.
It separates the spec from the rendering, so we can tune the figure system once and reuse it.
It keeps the output close to deck language instead of drifting into product UI or infographic clutter.

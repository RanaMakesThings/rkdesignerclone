# Copy Source Doc

## Core thesis

Residency programs repeatedly answer policy questions that are already buried in
their own documents. A custom GPT can turn those static PDFs into a practical,
grounded policy assistant when the source files, instructions, and testing
approach are designed well.

## Tone

- practical
- plain-language
- non-defensive
- useful to non-technical educators and administrators

## Must-keep ideas

- this is for policy and administrative support, not patient care
- grounded answers matter more than flashy build steps
- document quality and testing quality determine usefulness
- the tool should cite sources and refuse when the answer is not supported

## Phrases or habits to avoid

- long generic LLM theory sections
- overclaiming that the tool "solves" compliance
- vendor-specific hype language
- implying that one model choice is permanently fixed

## Working rewrite direction

- define the object first
- show why it works second
- show what good answers look like third
- spend the back half on a current live walkthrough

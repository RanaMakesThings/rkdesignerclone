What this tool is

A custom GPT can act like a residency policy assistant.

The audience should understand the object before any build theory: a user asks a policy question, and the GPT answers from uploaded documents and instructions.

Ask

Example policy question

"Can a resident use vacation during an elective month, and who has to approve it?"

What the user wants

A fast answer, plain-language guidance, and a pointer back to the real policy source.

Answer

Grounded assistant response

Vacation can be requested during elective time if the request is submitted in advance and approved by program leadership. The handbook also notes that final approval depends on coverage and rotation requirements.

# Copy Source Doc

Default copy guidance for the first-pass Mentor Match deck.

## Tone

- clear
- optimistic
- practical
- human-centered
- specific without overselling

## Copy rules

- Write in plain language.
- Prefer short sentences over framework-heavy jargon.
- Focus on people, workflow, and outcomes before features.
- Use directional language when the claim is still assumption-based.
- Keep the talk accessible to both operators and supporters.

## Working phrase bank

- more intentional matching
- easier first connection
- clearer fit
- lower coordination friction
- mentorship that is easier to find and easier to start
- a lightweight workflow, not a heavy platform

## Avoid

- guaranteed outcomes
- inflated impact language
- unexplained acronyms
- feature lists with no user value
- claims that sound measured when they are still placeholders

## Working summary line

Mentor Match helps people find the right mentor more intentionally by turning
mentor discovery, pairing, and first contact into a simpler workflow.

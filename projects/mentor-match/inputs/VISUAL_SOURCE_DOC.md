# Visual Source Doc

Default visual guidance for the first-pass Mentor Match deck.

## Direction

Make the deck feel:

- warm
- credible
- human
- lightweight
- forward-moving

## Preferred visual families

- relationship maps
- guided workflow diagrams
- profile-card systems
- simple scorecard or roadmap panels
- stakeholder outcome frames

## Visual rules

- Use one primary idea per slide.
- Favor clean cards, connectors, and directional flow over dense UI chrome.
- Keep the human element visible even on product or workflow slides.
- Make the matching concept feel intentional and supportive, not robotic.
- Use whitespace generously so the talk reads fast.

## Avoid

- handshake cliches
- generic stock-business teams
- overcomplicated backend diagrams
- fake data dashboards unless clearly conceptual
- visual metaphors that make the process feel cold or opaque

## Color and mood

- start from a calm, bright canvas
- use one confident accent color and one warm support accent
- avoid heavy dark-mode styling for this deck
- keep contrast strong enough for projected presentation use

# Mentor Match

Working project for a short presentation: `Mentor Match`.

This folder is the project home for:

- the current seven-minute deck backbone in `deck-spec.json`
- the human-readable copy companion in `master-slide-specs.md`
- the execution/status map in `deck-matrix.md`
- the working source notes in `inputs/PROGRAM_NOTES.md`
- the copy guardrails in `inputs/COPY_SOURCE_DOC.md`
- the visual guardrails in `inputs/VISUAL_SOURCE_DOC.md`
- the current per-slide packets in `slide-packets/`

## Working goal

Turn a blank project into a concise overview deck that:

- explains the Mentor Match problem space clearly
- introduces the product as a structured matching workflow
- shows why the idea matters for mentees, mentors, and operators
- states the first-phase goals and what the pilot needs next

## Important note

This first pass was scaffolded without imported Mentor Match source documents
found in the workspace.

That means:

- product specifics are drafted from reasonable assumptions, not confirmed docs
- there are no validated metrics, screenshots, or testimonials yet
- any external-facing version should replace the assumptions before use

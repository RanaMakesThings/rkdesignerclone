# Visual Source Doc

## Primary visual constraints

- final packaging should respect the SAEM PowerPoint template
- use the conference shell for footer / numbering / delivery consistency
- slides should read cleanly for mixed technical audiences

## Reference sources

- SAEM template:
  `assets/powerpoint-template/saem-annual-meeting-powerpoint-template.pptx`
- workshop preview:
  `references/source-deck/workshop-packet-preview.png`
- original deck:
  `references/source-deck/connor-original-deck.pptx`

## Desired visual direction

- fewer dense text blocks
- more direct `question -> answer -> why this is good` surfaces
- cleaner step maps for the live walkthrough
- interface screenshots with annotations for builder slides
- restrained card systems for governance / best-practice slides

## Avoid

- heavy theory diagrams
- duplicated best-practice slides with only one bullet each
- decorative visuals that do not help workshop comprehension

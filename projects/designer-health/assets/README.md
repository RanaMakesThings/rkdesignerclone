# Deck Assets

Canonical reusable deck-global assets live here.

- [manifest.json](/Users/kabeer/Code/rkdesignerclone/projects/designer-health/assets/manifest.json)
  is the deck-level asset manifest
- linked assets stay in checked-in subfolders such as
  [logo](/Users/kabeer/Code/rkdesignerclone/projects/designer-health/assets/logo)

Slides can link to these reusable assets through their slide-local asset
manifests.

Each asset record keeps:

- `id`: semantic slug for linking and references inside manifests
- `assetId`: global numbered handle such as `asset-000001` for precise review
  and discussion

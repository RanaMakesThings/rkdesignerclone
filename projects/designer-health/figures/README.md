# Designer Figures

Project-local figure artifacts for the Designer deck.

## Layout

- `briefs/`
  - slide briefs and input prompts
- `ideation/`
  - checked-in ideation artifacts
- `compositions/`
  - composition decisions before spec
- `render-briefs/`
  - final pre-spec visual lock
- `specs/`
  - canonical figure specs for this deck

Use this folder as the source of truth for Designer-specific figure work.

Reusable workflow docs and templates still live in `projects/figures/`.

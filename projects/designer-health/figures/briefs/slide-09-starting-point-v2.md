# Slide 9 Figure Brief

Header:

- `Current AI helps around the visit. Vox changes how the visit starts.`

Subheader:

- `Most assistive AI reduces operational or documentation work. Vox gives the`
  `clinician a structured brief at the beginning of the visit.`

Scope:

- Design the figure / graphic area for the slide.
- The figure may include the slide title and subtitle in the native spec, but
  the visual job is to make Vox's position in the workflow obvious.

Must-keep logic:

- show that support exists around the visit already
- place one explicit `Vox-prepared brief` object at the `Start of visit`
- make the center object feel like the thing that changes the clinician's
  starting state
- supported zones can carry small tags such as:
  - `scheduling`
  - `reminders`
  - `documentation support`
  - `note generation`
  - `clerical relief`
- the center brief should imply:
  - `What matters`
  - `What happened when`
  - `What still needs confirmation`
- an optional tiny line near the center can read:
  - `Where clinical reasoning begins`

Desired effect:

- make the category difference legible in under 3 seconds
- make Vox feel like a distinct starting-state layer, not another admin tool
- stay premium, strategic, and calm rather than argumentative

Helpful directions:

- one journey strip with a blue center brief
- one threshold composition with the center brief crossing the encounter start
- one quiet hallway-context branch
- one clipboard-context hybrid branch

Avoid:

- competitor matrices
- anti-scribe rhetoric
- generic empty-gap diagrams with no explicit Vox object
- fake product UI
- too many tags
- dense captions or strategy-framework language

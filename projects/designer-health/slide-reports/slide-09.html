Slide 8 — Category definition / positioning / competitive landscape

Source note

This section incorporates **Slide 09 Concept Spec v0.3**. That source file preserves the historical workstream label “Slide 09,” even though the current renumbered deck places this category-defense slide in the **Slide 8** slot after the Slide 4 / Slide 5 merge.

Slide job

Prevent Vox from being mentally collapsed into documentation AI, scribe extension, note automation, or generic assistive AI.

This is the category-defense slide.

Its job is to make two things clear at the same time:

  1. clinician buy-in for AI is already real
  2. the competitive landscape is much thinner for tools that change the visit itself than for tools focused on documentation

Audience should leave believing

**Vox is built to change the visit itself, not just the record it produces.**

Core claim

**Clinician buy-in for AI is already real. But most competition is concentrated in documentation, while the landscape for tools that change the visit itself is still much thinner.**

Surface mode

Direct-surface mode.

The locked audience-belief line is strong enough to serve as the header. The locked core-claim line is strong enough to serve as the subheader. Do not translate these into a new header/subheader pair unless layout later forces compression.

Strategic role in deck

This is the category-defense slide. It is not mainly about saying “we are unique.” It is about preventing the audience from slotting Vox into the wrong category.

The slide is now about:

  • validated clinician AI adoption
  • dense competition in documentation
  • a thinner lane for tools that change the visit itself

Current running copy plan

**Header** Vox is built to change the visit itself, not just the record it produces.

**Subheader** Clinician buy-in for AI is already real. But most competition is concentrated in documentation, while the landscape for tools that change the visit itself is still much thinner.

Why this version is stronger

This version fixes four problems in the prior framing:

  • it does not imply that current tools only matter after the visit
  • it does not over-index on “the start of the visit” as the main distinction
  • it makes the distinction about where value lands, not when software runs
  • it states the competitive-landscape point directly instead of implying it indirectly

Figure burden

The figure must do four jobs:

  1. show that clinician adoption of AI is already real
  2. show where competition has become dense
  3. show that the competitive field is much thinner for tools that change the visit itself
  4. place Vox visibly in that thinner lane

Figure logic

**Clinician AI is already validated, but the densest competition is in documentation; Vox sits in the much thinner lane of tools built to change the visit itself.**

Current running figure plan

The preferred direction remains a two-panel density-versus-whitespace layout.

Left side

  • ambient scribe
  • note generation
  • clerical relief
  • documentation support

Right side

Thinner visit-impact lane

  • one blue VOX chip/object
  • maybe one faint secondary outline if needed
  • otherwise whitespace

The visual should argue:

  • clinician AI is real
  • documentation is where density has formed
  • Vox occupies the thinner lane of tools trying to change the visit itself

Keep from current direction

  • the category-defense role
  • the left/right density contrast
  • one blue VOX object anchoring the thinner lane
  • the idea that AI adoption is already real

Change from prior direction

  • move away from “after the visit” as the main claim
  • move away from “opening clinical work” as the primary surface phrase
  • stop forcing alternate header/subheader copy when the locked truth is stronger
  • make the slide about documentation density vs visit-impact whitespace
  • make the competitive-landscape point explicit

Assessment

This is one of the most important slides in the deck and still one of the most design-sensitive. The concept is now meaningfully tighter than before. The remaining work is execution:

  • panel labels
  • chip wording
  • density balance
  • final layout inside the template
  • whether the subheader needs only visual tightening, not conceptual rewriting

What to avoid

  • a competitor matrix
  • a workflow explainer
  • an anti-scribe attack slide
  • a semantic “we are different” slide without a visual market argument
  • a timing argument about when software runs rather than where its value lands
  • a slide that says or implies Vox has no competitors at all

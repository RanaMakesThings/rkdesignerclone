Locked direction:
- one shared outer frame
- internal vertical split only
- left = patient reality
- right = AI synthesis

Hard constraints:
- no full app shell
- no sidebars, top nav, or tabs
- no trace or raw LLM artifacts
- no bright consumer-app colors
- no generic SaaS card grid

Layout:
- one large white card
- subtle outer border and subtle shadow
- internal divider
- left column about 40%
- right column about 60%

Left column:
- title can be `What We Know` or `Patient History & Status`
- categories:
  - SOCIAL CONTEXT
  - REPORTED SYMPTOMS
  - KEY NEGATIVES
- flat rows, not heavily bordered mini-cards
- each row should include:
  - title line
  - optional value line
  - evidence token on the right like `[Turn 14]`
  - soft state pill

State pill semantics:
- present = soft blue pill with dark blue text
- absent = soft red pill with dark red text
- unresolved = pale amber or warm gray pill
- no icons inside pills

Right column:
- title must be `Considerations to Confirm`
- three soft gray candidate blocks
- each block includes:
  - rank
  - diagnosis name
  - confidence pill like `High match`
  - Supports
  - Against
  - Unknowns
- include one dedicated `Highest Yield Next Question` block at the bottom of
  the right column

Reasoning glyph system:
- Supports use a tiny muted green `↑`
- Against use a tiny muted red `↓`
- Unknowns use a tiny amber `○` or `?`
- these are typographic glyphs, not big icons
- movement chips like `SAME 1→1` should be removed entirely
